# 交互式礼物设计规格

> 日期：2026-06-24
> 状态：待审查
> 目标：为生日祝福网页的"礼物"部分添加交互体验，包含点亮星星和拼字两个小游戏

## 背景

当前网页的礼物部分（礼物盒打开后）只有预设的烟花动画和祝福卡展示，用户只能被动观看，缺乏参与感。需要将被动观赏变为主动交互，让用户"亲手"拆开礼物。

## 整体流程

```
故事放映（保持不变）
    ↓
"生日快乐"发光标题 → 礼物盒弹出 → 撕开（保持不变）
    ↓
阶段 A：点亮星星（交互）  ~15秒
    ↓ 全部点亮
阶段 B：拼出"生日快乐"（交互）  ~15秒
    ↓ 拼完
阶段 C：烟花 + 祝福卡 + 快递提醒（保持不变）  ~20秒
    ↓
永久定格
```

阶段 A 和 B 是新增的交互环节，替换原来的"直接放烟花"。阶段 C 保持现有逻辑不变。

## 阶段 A：点亮星星

### 视觉设计
- 礼物盒撕开后，画面在 0.8 秒内渐暗（背景 opacity 降低）
- 屏幕上散布 **12 颗星星**，使用 SVG `<polygon>` 或 `<path>` 绘制五角星
- 星星初始状态：半透明灰色（fill="#555"，opacity=0.3），无发光效果
- 星星大小不一（SVG 坐标系中 8~16px 半径），随机分布在视口中间 70% 区域（避免边缘）
- 屏幕底部居中显示进度文字："✦ 0 / 12"，字体颜色 rgba(245,230,202,0.5)

### 交互设计
- 用户点击/触摸一颗暗星 → 该星执行以下动画：
  1. 颜色从灰色过渡到金色（#f6c343），opacity 从 0.3 过渡到 1，transition 0.3s
  2. 同时添加 SVG filter 发光效果（glow-soft）
  3. 从星星位置向外爆出 6~8 个小粒子（SVG circle），向外扩散并淡出，持续 0.5 秒
  4. 播放"叮"音效（Web Audio API，频率 800Hz，持续 0.15s）
- 进度文字实时更新（"✦ 3 / 12"）
- 已点亮的星星不可再次交互

### 通关动画
- 最后一颗星点亮后，等待 0.5 秒
- 所有 12 颗星同时闪耀（opacity 脉冲 1→0.6→1，持续 0.4 秒）
- 画面渐亮回到正常（0.6 秒）
- 过渡到阶段 B（0.3 秒延迟）

## 阶段 B：拼出"生日快乐"

### 视觉设计
- 屏幕上方（y=250~300 区域）排列 **4 个空槽位**：
  - 每个槽位是虚线矩形（stroke="#f6c343"，stroke-dasharray="4,4"，opacity=0.4）
  - 尺寸 60×60 SVG 单位，间距 20 单位
  - 槽位下方有小字提示序号："① ② ③ ④"（可选，降低难度）
- "生""日""快""乐" 四个字块：
  - 每个字块是 SVG `<text>` 元素，字号 36，填充 #f5e6ca
  - 背景有圆角矩形（rx=8，fill="#1a1a3e"，stroke="#f6c343"，stroke-width=1.5）
  - 初始随机散落在屏幕下方区域（y=450~650），带有轻微上下浮动动画（translateY ±5px，周期 2s）
  - 四个字块的初始 x 位置随机但互不重叠

### 交互设计
- 拖拽机制：
  - mousedown / touchstart 在字块上 → 记录偏移量，字块提升到最前（z-index），scale 放大到 1.1
  - mousemove / touchmove → 字块跟随手指/鼠标移动
  - mouseup / touchend → 判断字块中心是否落在对应槽位范围内（±30px 容差）
    - **放对位置**：字块吸附到槽位中心，锁定不可再拖，播放"叮"音效 + 发光效果
    - **放错位置**：字块弹回散落区域的随机位置（transition 0.3s ease-out），播放轻微"咚"音效
- 判定逻辑：每个字有唯一对应的槽位（"生"→第1槽，"日"→第2槽，"快"→第3槽，"乐"→第4槽）

### 通关动画
- 四个字全部归位后，等待 0.3 秒
- 四个字同时放大到 1.2 倍 + 发光（glow-strong filter），持续 0.5 秒
- 然后四个字整体淡出（0.4 秒）
- 过渡到阶段 C

## 阶段 C：庆祝收尾（保持不变）

保持现有逻辑：
1. 烟花表演秀（5 波，~5 秒）
2. 飘浮爱心 + "Happy Birthday" 文字
3. 祝福卡弹入（弹性动画）
4. 祝福语逐行显示
5. 卡片淡出 → 全屏快递提醒
6. 永久定格

唯一变化：阶段 C 的触发从"礼物盒撕开后自动开始"变为"用户完成拼字后开始"。

## 音效设计

使用 Web Audio API 合成，无需外部文件：

| 事件 | 音效描述 | 实现 |
|------|---------|------|
| 点亮星星 | "叮"清脆声 | OscillatorNode, 800Hz, 0.15s, sine |
| 放对字块 | "叮"清脆声（同上） | 同上 |
| 放错字块 | "咚"低沉声 | OscillatorNode, 300Hz, 0.1s, sine |
| 拼字通关 | 和弦上升 | 依次播放 523/659/784Hz, 各 0.15s |

AudioContext 在用户首次点击时初始化（浏览器自动播放策略要求）。

## 技术约束

- 纯 HTML/CSS/JS 单文件，所有图形内联 SVG
- 不依赖外部图片、库、CDN
- 移动端适配：触摸事件兼容，字块/星星足够大（最小触摸目标 44px）
- 所有动画使用 requestAnimationFrame 或 CSS transition
- SVG viewBox 保持 500×800，preserveAspectRatio="xMidYMid meet"

## 与现有代码的集成点

- `onTearDone()` 函数：当前直接启动烟花表演，需改为启动阶段 A
- 新增 `startStarPhase()` 函数：管理阶段 A 逻辑
- 新增 `startPuzzlePhase()` 函数：管理阶段 B 逻辑
- 现有 `startCelebration()` 函数：保持不变，但从阶段 B 的完成回调中触发
- SVG 结构：在 main-svg 中新增 stars-layer、puzzle-layer 图层
