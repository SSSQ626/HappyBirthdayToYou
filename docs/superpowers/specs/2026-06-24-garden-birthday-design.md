# 花园生日互动网页 — 设计规格

> 日期：2026-06-24
> 状态：待实现
> 更新：2026-06-24（Grill-me 审查 + 个性化信息）

## 1. 概述

一个可爱卡通风格的生日祝福互动网页，暖色夕阳色调。为 **LSQ** 的 **2026年6月26日** 生日定制。用户点击/触摸屏幕即可在花园场景中触发卡通元素特效，最终通过擦除效果揭晓礼物信息。

**核心体验**：先看贺卡 → 进入花园自由玩耍 → 揭晓礼物

## 2. 个性化信息

| 信息 | 值 | 使用位置 |
|------|-----|----------|
| 主人公名字缩写 | **LSQ** | 贺卡标题、Doraemon对话、揭晓文字 |
| 生日日期 | **2026.6.26** | 贺卡日期、揭晓卡片底部 |

## 3. 技术约束

- 单个 `index.html`，所有样式和脚本内联
- 外部引入：
  - Google Fonts CDN（`Baloo 2` 字体）
  - CDN 音频文件（背景音乐 + 点击音效）
- 不引入任何图片资源，所有视觉效果用 CSS 几何图形 + Canvas + emoji 实现
- 响应式设计，横竖屏都支持，电脑和手机均适配
- 自动播放，无需用户复杂操作

## 5. 场景设计

### 5.1 贺卡开场

- 屏幕中央，卡通风格贺卡从下方弹入
- 贺卡内容：
  - 第一行（大字）：**"LSQ"**（手写体，突出名字）
  - 第二行：**"生日快乐"**（Baloo 2 字体，圆润可爱）
  - 第三行（小字）：**"2026.6.26"**（日期，浅色）
  - 装饰：小花 🌸 + 跳动爱心 ❤️
- 贺卡微微摇摆（左右摇晃 3°），暗示可点击
- 贺卡有厚度感（CSS `box-shadow` 多层 + 微妙渐变）
- 点击后 **3D 翻页打开**：
  - CSS `perspective` + `rotateY` 实现翻转
  - 贺卡像书页一样向左翻开
  - 翻开过程中逐渐透明，露出后面的花园场景
  - 翻页持续约 0.8 秒

### 5.2 花园互动（核心场景）

**配色风格：暖色夕阳**
- 主色调：橙色 `#F4A460`、暖黄 `#FFD700`、柔粉 `#FFB6C1`
- 天空：橙 → 粉 → 浅紫渐变
- 草地：深绿到浅绿渐变，底部略暗
- 花朵：暖色系（橙、粉、黄）
- 整体温暖柔和，像傍晚花园

**背景层次：**
- 底层：暖色渐变天空 + 2-3 朵白云缓慢飘动（CSS `translateX` 动画，20-30秒一个周期）
- 中层：绿色草地（圆弧起伏的轮廓）+ 5-8 朵 CSS 绘制的小花装饰
- 远景：几个 CSS 圆形树丛（深绿色，半透明）
- 顶层：透明交互区域，接收点击/触摸事件

**点击特效（随机一种，每次只出一种）：**
- 🌸 花朵：从点击处弹出，放大后轻轻左右摇晃，3秒后淡出
- 🦋 蝴蝶：从点击处飞出，沿贝塞尔曲线飞行2秒，然后停住扇翅
- 🎈 气球：从点击处向上飘走，左右轻微摆动，飘出屏幕后移除
- ⭐ 星星：从点击处弹出，旋转+闪烁，2秒后缩小消失
- 🌈 彩虹：从点击处向两侧展开弧形，停留1秒后消散

每个元素带弹性动画（`cubic-bezier(0.34, 1.56, 0.64, 1)`），手感 Q 弹。同时触发 10-15 个彩色粒子爆发（Canvas 绘制，暖色系粒子）。

**Doraemon 常驻元素：**
- 右下角，CSS 几何图形拼出的经典轮廓，**中号（约 200-250px）**
- 蓝色圆头 + 白色脸 + 红鼻子 + 铃铛
- 偶尔眨眼睛（CSS `scaleY` 动画，每隔 4 秒触发一次，持续 0.2 秒）
- Doraemon 下方有小字 "点我~" 提示（出现5秒后淡出）

**Doraemon 点击互动：**
- 点击 Doraemon → 它向上跳起（`translateY(-80px)`）+ 轻微旋转
- 头顶弹出气泡框：**"LSQ，生日快乐呀！"**
- 停留 1.5 秒后，跳回右下角原位
- 气泡框淡出

### 5.3 礼物揭晓

**触发方式：**
- 互动 **15 秒**后自动触发
- 或点击右下角礼物按钮手动触发（礼物按钮在 Doraemon 旁边，小图标 🎁）

**动画序列：**
1. Doraemon 从右下角跳到屏幕中央，说"LSQ，生日快乐呀！"，跳回
2. 弹出气泡框：**"LSQ，有个快递给你！"**
3. 停留 1 秒后气泡框消失
4. 出现卡片，被金色涂层覆盖（Canvas 绘制）
5. 涂层上显示"刮开查看"文字
6. 自动擦除：从中心向外扩散的实心圆（Canvas `destination-out`），持续 1.5 秒
7. 露出内容：
   - 第一行（大字）：**"快递ing，注意查收哦 📦"**
   - 第二行（小字）：**"2026.6.26 · LSQ的专属生日礼物"**
8. Doraemon 在卡片旁边，底部小字：**"快去查收吧！"**
9. 背景粒子持续飘动，画面定格

## 6. Doraemon CSS 绘制方案

用 CSS 几何图形拼出经典特征：

| 部件 | 实现方式 |
|------|----------|
| 头部 | 蓝色圆形 `border-radius: 50%`，约 200-250px |
| 脸部 | 白色椭圆叠在蓝色圆上 |
| 眼睛 | 两个白色小椭圆 + 黑色瞳孔 |
| 鼻子 | 红色小圆 |
| 嘴巴 | 弧形线条（`border-radius` 模拟） |
| 铃铛 | 金色小圆 + 横线装饰 |

眨眼动画：每隔 4 秒触发一次 `scaleY` 变换，持续 0.2 秒。

## 7. 音频设计

- **背景音乐**：轻柔的 Happy Birthday 旋律，CDN 链接，循环播放
- **点击音效**：简单的"啵"音效，CDN 链接
- **揭晓音效**：叮咚/魔法音效，CDN 链接
- 页面左下角有静音按钮（🔊/🔇 图标），用户可控制
- 页面加载后首次交互时才播放音频（遵守浏览器自动播放策略）

## 8. 性能设计

- 每次点击最多生成 1 个 emoji 元素 + 15 个 Canvas 粒子
- emoji 元素动画结束后自动移除 DOM
- Canvas 粒子用对象池复用，不频繁创建/销毁
- 手机端粒子数量减半（6-8个）
- 所有动画用 `transform` 和 `opacity`，不触发重排
- 白云和花朵装饰用 CSS 动画，不消耗 JS 资源

## 10. 响应式适配

- 768px 以下：贺卡缩小、Doraemon 缩小至 150px、字体减小
- 480px 以下：进一步缩小，粒子数量减半
- 横屏和竖屏都自适应布局
- 触摸事件与点击事件同等处理
